Una API para gestionar **máquinas/equipos industriales, sensores, mediciones, mantenimientos y alertas**.

Tecnologías
- 🐍 **Python 3**
- 🌐 **FastAPI / Django / Flask**
- 🔌 **REST APIs**
- 🐘 **PostgreSQL / MySQL**
- 🧪 **Pytest + Git**
- 🐳 **Docker + CI/CD**

|Tecnología|Uso|
|---|---|
|Python 3|Backend|
|Django|Framework|
|Django REST Framework|REST API|
|PostgreSQL|Base de datos|
|Pytest|Testing|
|Git/GitHub|Control de versiones|
|Docker|Contenedores|
|GitHub Actions|CI/CD|
|Swagger/OpenAPI|Documentación|
|JWT|Autenticación|
