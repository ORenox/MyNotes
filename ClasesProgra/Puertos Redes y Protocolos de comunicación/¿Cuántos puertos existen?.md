Los puertos están numerados:

```
0 - 65535
```

Son **65,536 posibles números de puerto**.

Se suelen dividir en:

```
0–1023
```

**Well-known ports**

Por ejemplo:

```
22   SSH
80   HTTP
443  HTTPS
53   DNS
25   SMTP
```


**registered ports**.
```
1024–49151
```

**dynamic/private ports**, utilizados frecuentemente para conexiones temporales.
```
49152–65535`
```
