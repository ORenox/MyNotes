Este concepto te va a aparecer muchísimo con servidores.

Supongamos que tu servidor dice:

```
0.0.0.0:8080
```

No significa que `0.0.0.0` sea una computadora.

Significa aproximadamente:

> **Escuchar en todas las interfaces de red disponibles.**

Tu computadora podría tener:

```
127.0.0.1       → localhost
192.168.1.20    → Wi-Fi/LAN
10.0.0.5        → otra interfaz
```

Si el servidor escucha en:

```
127.0.0.1:8080
```

solamente acepta conexiones desde localhost.

Pero si escucha en:

```
0.0.0.0:8080
```

puede aceptar conexiones provenientes de otras interfaces, sujeto al firewall y demás configuración.

Esto explica por qué a veces haces:

```
http://localhost:8080
```

y funciona en tu PC, pero desde tu teléfono:

```
http://192.168.1.20:8080
```

no funciona.

El servidor podría estar escuchando únicamente en `127.0.0.1`.
