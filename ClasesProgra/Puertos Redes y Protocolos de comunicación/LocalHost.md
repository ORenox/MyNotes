`localhost` significa:

> **Esta misma computadora.**

Normalmente corresponde a:

```
127.0.0.1
```

Por ejemplo:

```
localhost:8080
```

es equivalente a:

```
127.0.0.1:8080
```

Si tienes Spring Boot ejecutándose en:

```
localhost:8080
```

y abres:

```
http://localhost:8080
```

estás accediendo al servidor que tienes ejecutándose en **tu propia máquina**.
