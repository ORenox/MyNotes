Given a string `s`, return _the longest_ _palindromic_ _substring_ in `s`.

**Example 1:**

**Input:** s = "babad"
**Output:** "bab"
**Explanation:** "aba" is also a valid answer.

**Example 2:**

**Input:** s = "cbbd"
**Output:** "bb"

**Constraints:**

- `1 <= s.length <= 1000`
- `s` consist of only digits and English letters.

---
# Solución con fuerza bruta

```python
class Solution:

def longestPalindrome(self, s: str) -> str:

	n=len(s)
	
	rpt=s[0]
	
		for i in range(n):
		
			aux = s[i]
			
			for j in range(i+1,n):
			
				aux += s[j]
				
				if(aux == aux[::-1]):
				
					if( len(aux) > len(rpt)):
					
					rpt=aux
	
	return rpt
```

# Solución con DP

```python
class Solution:

def longestPalindrome(self, s: str) -> str:

n = len(s)

if n <= 1:
	return s
# Matriz DP
dp = [[False] * n for _ in range(n)]

start = 0
max_length = 1

# Todos los caracteres individuales son palíndromos
for i in range(n):
	dp[i][i] = True

# Evaluamos substrings de menor a mayor longitud
for length in range(2, n + 1):
	for i in range(n - length + 1):
		j = i + length - 1
		# Los extremos deben ser iguales
		if s[i] == s[j]:
			# Si tiene longitud 2 o 3, el interior
			# es automáticamente palíndromo
			if length <= 3:
				dp[i][j] = True
		
			# Para strings más largos, comprobamos
			
			# el substring interior
			else:
				dp[i][j] = dp[i + 1][j - 1]
		# Si encontramos uno más largo, lo guardamos
		if dp[i][j] and length > max_length:
			start = i
			max_length = length
return s[start:start + max_length]
```
